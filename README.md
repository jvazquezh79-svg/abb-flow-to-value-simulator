# ABB Flow-to-Value Simulator v3 · OEE Dinámico

Simulación interactiva para practicar el cálculo de **OEE** y la toma de decisiones de mejora con **TPM, RCA, A3 y 8D**.

**▶ Abrir el simulador:** https://jvazquezh79-svg.github.io/abb-flow-to-value-simulator/

## ¿Qué es?

Una práctica individual de 25 pantallas en la que el participante simula un turno de producción con datos sintéticos, calcula el OEE (disponibilidad × desempeño × calidad), prioriza pérdidas y defiende sus decisiones. Las preguntas son de nivel intermedio-alto y están diseñadas para evitar respuestas obvias.

## Recorrido

1. Inicio
2. Conceptos
3. Simulación de turno
4. OEE dinámico
5. TPM
6. Análisis de causa raíz (RCA)
7. A3 / 8D
8. Resultado

## Cómo usarlo

- En línea: abre el enlace de arriba desde cualquier navegador (computadora, tableta o celular).
- Sin conexión: descarga `index.html` y ábrelo directamente en el navegador. No requiere instalación ni librerías externas.

## Aviso de uso

Aplicación desarrollada con fines académicos y de práctica ejecutiva. Los datos son **sintéticos** y no representan información operativa real, confidencial o histórica de ninguna empresa.
